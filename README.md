# Recopilación de tráilers de películas famosas
Este trabajo es de la asignatura GDIE (Gestión y Distribución de la Información Empresarial).
Se trata de construir una básica página web en la que reproducir un vídeo multimedia distribuido y códificado de diferentes
formas en cada iteración de la práctica.
Además de crear y gestionar datos VTT para aportar información extra según el momento y contenido del vídeo.
